# Personal Portfolio Webpage

A responsive Personal Portfolio Webpage developed using HTML and CSS to showcase frontend development projects, skills, and contact information.

This project is designed with a modern UI layout and responsive design for desktop and mobile devices.

# Features
- Responsive Single Page Website
- Navigation Bar
- Hero Section
- About Section
- Projects Showcase
- Contact Information Section
- Responsive Design
- Modern UI Design
